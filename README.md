# DPD Stock System

ระบบจัดการพัสดุคงคลังของกองกรรมวิธีข้อมูล (DPD) สำหรับติดตามยอดคงเหลือ การรับ–เบิกพัสดุ บุคลากร และรายงานสรุป

> สถานะความปลอดภัย: รุ่นปัจจุบันยังเป็นระบบต้นแบบแบบ Static Site และยังไม่เหมาะสำหรับเก็บข้อมูลจริงที่มีความอ่อนไหว จนกว่าจะย้ายการยืนยันตัวตนและการกำหนดสิทธิ์ไปตรวจสอบฝั่งเซิร์ฟเวอร์

## ความสามารถปัจจุบัน

- Dashboard และการแจ้งเตือนพัสดุใกล้หมด
- จัดการรายการพัสดุ รับเข้า เบิกออก และปรับยอด
- ประวัติความเคลื่อนไหวและใบเบิก
- รายชื่อบุคลากร
- รายงานและส่งออกข้อมูล
- สำรองและกู้คืนข้อมูล
- รองรับภาษาไทยและอังกฤษ

## โครงสร้างโปรเจกต์

- `index.html` — หน้าเว็บหลัก
- `js/app.js` — ลอจิกของระบบ
- `css/style.css` — รูปแบบการแสดงผล
- `assets/` — รูปภาพ โลโก้ และสื่อ
- `docs/` — เอกสารสถาปัตยกรรมและการติดตั้ง

## การใช้งานสำหรับนักพัฒนา

โปรเจกต์เป็น Static Site จึงเปิดผ่านเว็บเซิร์ฟเวอร์ท้องถิ่นได้ เช่น Visual Studio Code Live Server หรือคำสั่ง:

```bash
python -m http.server 8080
```

จากนั้นเปิด `http://localhost:8080`

## แผนปรับปรุงความปลอดภัย

1. ใช้ Google Workspace เป็นผู้ยืนยันตัวตน
2. อนุญาตเฉพาะบัญชีและโดเมนของหน่วยงาน
3. ตรวจสิทธิ์ทุกคำขอที่ Backend
4. ย้ายข้อมูลหลักออกจาก `localStorage`
5. เพิ่มบทบาท `admin`, `stock`, `approver` และ `viewer`
6. เพิ่ม Audit Log และการสำรองข้อมูลแบบมีเวอร์ชัน
7. ลบข้อมูลจริงและรหัสผ่านออกจาก Git history

รายละเอียดอยู่ที่ [แผน Google Workspace](docs/GOOGLE_WORKSPACE_AUTH_PLAN.md) และ [นโยบายความปลอดภัย](SECURITY.md)\n\nBackend Google Sheets รุ่นเตรียมใช้งานอยู่ที่ `google-apps-script/` พร้อม [คู่มือติดตั้งและ Deploy](docs/GOOGLE_SHEETS_BACKEND_SETUP.md) โดย Preview ยังคงเป็น Demo และไม่เชื่อมข้อมูลจริง

## โหมดทดสอบสาธารณะ

branch `security-hardening` ทำงานใน Demo Mode และแยกออกจากระบบจริง:

- ไม่เชื่อม Google Sheets หรือ Apps Script ของระบบจริง
- ใช้คีย์ `dpd_demo_*` ใน browser storage
- ใช้ข้อมูลบุคลากรสมมติเท่านั้น
- มีปุ่มล้างข้อมูลสาธิต
- ตรวจไฟล์ Backup ก่อนนำเข้า
- รองรับวงจรคำขอเบิกครบขั้น: ส่งคำขอ → อนุมัติ/ปฏิเสธ → จ่ายพัสดุ → รับคืนหรือปิดรายการ
- Dashboard มีคิวงานตามบทบาท: รออนุมัติ รอจ่าย และรอคืน/ปิด พร้อมเปิดประวัติที่กรองสถานะให้อัตโนมัติ
- ตัดสต็อกเฉพาะตอนเจ้าหน้าที่คลังยืนยันจ่าย และเพิ่มคืนเฉพาะตอนรับคืน
- รองรับอนุมัติ จ่าย รับคืน และปิดบางส่วน พร้อมยอดคงค้างและ Activity Log ของทุกครั้ง
- สร้างเลขเอกสาร `REQ`, `ISS`, `RET` อัตโนมัติ พร้อม Timeline ผู้ดำเนินการและเวลา
- ตรวจนับสต็อกจริง เปรียบเทียบยอดระบบ คำนวณส่วนต่าง และบันทึกผู้ตรวจนับ
- รวมผลต่างจากการตรวจนับไว้ในประวัติและรายงาน

บัญชีทดสอบ:

| บัญชี | รหัสผ่าน | บทบาท |
|---|---|---|
| `demo-admin` | `admin-demo` | ผู้ดูแล |
| `demo-stock` | `stock-demo` | เจ้าหน้าที่คลัง |
| `demo-approver` | `approver-demo` | ผู้อนุมัติ |
| `demo-viewer` | `viewer-demo` | ผู้ดู/ขอเบิก |

บัญชีเหล่านี้เป็นข้อมูลสาธิตที่ตั้งใจให้เปิดเผยและห้ามนำไปใช้กับระบบจริง
